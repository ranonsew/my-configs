## Context continuity

For ongoing tasks, follow the context-continuity skill.

At the beginning of work in a project:
- Inspect .context/INDEX.md if present.
- Read the active task state when relevant.
- Preserve established objectives, decisions, and constraints.
- Treat follow-up questions as continuations, not automatic
  change requests.

Load the context-continuity skill when:
- Establishing a substantive task
- Revisiting an earlier decision
- Handling corrections
- Debugging existing implementations
- Changing requirements
- Updating task progress
- Resuming work after a session change

Do not overwrite established decisions without justification.

Do not modify state files when editing is denied.

When the skill is unavailable, follow these principles using
the available conversation and project context.
